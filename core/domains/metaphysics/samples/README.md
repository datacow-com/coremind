### 图像样本 (images/)

由于版权和隐私原因，图像样本需要单独准备。建议使用以下类型：

- 命盘截图（脱敏处理）
- 八字排盘图
- 五行分布图

## 使用说明

```python
from core.domains.metaphysics.samples import load_text_samples, load_image_samples

# 加载文本样本
samples = load_text_samples()
for sample in samples:
    print(sample["content"])

# 加载图像样本
images = load_image_samples()
for img in images:
    print(img["path"], img["expected"])
```

## 注意事项

1. 所有样本数据均为虚构，仅用于测试
2. 图像样本需脱敏处理，不包含真实个人信息
3. 样本覆盖常见的命理文档格式
