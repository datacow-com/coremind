# OmniRAG 产品特性清单与规划

## 1. 产品概述

OmniRAG 是基于 LangGraph 架构的下一代智能知识中台，通过视觉驱动的数据解析、自适应混合检索和图导向的智能编排，解决传统 RAG 系统解析不准确、检索不精准、逻辑简单等核心痛点。

**核心价值主张：**

- 所见即所得的解析 (WYSIWYG Ingestion)：像人类阅读一样"看"文档
- 图导向的智能编排 (Graph-Native)：基于 LangGraph 的"检索-反思-修正"闭环
- 无缝生态集成 (API First)：从第一天起就是 Headless 架构

#### 2.3.1 模型网关（国内/国外）与多模态/Embed 接入

- 目标：提供 MaxKB/RAGFlow 级别的“可视化模型接入界面”，支持国内外主流大模型与本地模型，覆盖对话、视觉、多模态、嵌入与重排序。
- 提供商分区：
  - 国内：阿里云通义（DashScope）、月之暗面 Kimi（Moonshot）、百度千帆、智谱 GLM、DeepSeek
  - 国外：OpenAI、Anthropic、Gemini、OpenRouter
  - 本地：Ollama（多模型，含 llama / qwen / mistral 等）
- 能力矩阵：
  - 对话模型：chat-completion / streaming、工具调用（可选）
  - 多模态模型：vision（image-to-text / PDF截图）、表格识别 Prompt 支持
  - 嵌入模型：text-embedding（中文/英文双栈）、向量维度与归一化配置
  - 重排序模型：BGE-Reranker、Cohere Rerank（可选）
- 配置界面：
  - 提供商选择（国内/国外/本地 Tab）
  - 连接参数：`api_key`、`base_url`、`model`、`timeout`、`rate_limit`
  - 任务分配：解析（Vision）/ 检索（Embed）/ 对话（Chat）/ 重排（Rerank）模型绑定
  - 环境隔离：`dev/test/prod` 分环境密钥与配额，支持灰度与A/B
  - 密钥管理：密钥加密存储、审计日志、按租户/项目的密钥作用域
  - 验证与测试：一键“连接测试”，输出延迟、容量与错误码
- 验收指标：
  - 提供商支持数量 ≥ 10；多模态与嵌入能力覆盖率 ≥ 90%
  - 连接测试通过率 ≥ 99%；错误提示与自诊断信息完整
  - 每任务模型可独立配置与回退；支持配额与限流策略
- 风险与缓解：
  - 复杂配置易出错 → 模板与向导式配置、预设与推荐模型
  - 国内外网络差异 → 代理/直连双栈、就近路由与重试机制
  - 成本与合规 → 用量可视化、阈值告警、私有化与本地模型兜底

## 3. 里程碑规划

### 3.1 MVP (Phase 1) - "能读懂，能回答"

**时间周期：** 8-10 周
**核心目标：** 完成基于 Gemini 3 Vision 的 PDF 解析 + 基础 RAG 问答

**关键交付：**

1. Visual Parser (PDF -> Markdown)
2. Milvus 集成 + 混合检索
3. 基于 LangGraph 的线性流程 (Retrieve -> Generate)
4. 简单的 Stream Chat UI
5. 基础 API 接口

**验收标准：**

- PDF 解析速度 < 3秒/页
- 首字延迟 (TTFT) < 1秒
- 单节点支持 50 QPS
- 基础聊天功能可用

### 3.2 Phase 2 - "能思考，能联网"

**时间周期：** 6-8 周
**核心目标：** 引入 Router 和 Web Search，减少幻觉

**关键交付：**

1. Intent Router 节点
2. Web Search Tool 集成
3. Self-Correction (Grade Documents) 节点
4. 后台管理界面（知识库管理、Prompt 编排）
5. 运营分析基础功能

**验收标准：**

- 意图识别准确率 ≥ 88%
- 联网问题覆盖率 ≥ 80%
- 幻觉率 < 5%
- 管理界面功能完整

### 3.3 Phase 3 - "全平台，API化"

**时间周期：** 8-10 周
**核心目标：** 对外开放能力，支持复杂工作流

**关键交付：**

1. OpenAPI 完整文档
2. JS 嵌入组件
3. 多租户权限系统
4. 运营数据看板
5. 插件系统基础

**验收标准：**

- API 覆盖率 ≥ 100%
- 集成时间 < 5 分钟
- 权限控制粒度 ≤ 记录级
- 插件扩展点 ≥ 10 个

## 10. 总结

OmniRAG 通过 ACIS 四层架构设计，结合视觉驱动的数据解析、图导向的智能编排和 API First 的生态策略，构建了一个具有极强市场竞争力的智能知识中台。产品采用 MVP + 迭代的开发模式，分三个阶段实现从基础功能到完整生态的演进，最终成为企业数字化转型的核心基础设施。

**关键成功要素：**

1. 技术领先性：视觉解析 + LangGraph 的双重技术壁垒
2. 产品完整性：从解析到应用的全链路覆盖
3. 生态开放性：API First 的开放平台策略
4. 运营精细化：数据驱动的持续优化机制

通过严格执行本规划，OmniRAG 有望成为下一代 RAG 系统的标杆产品。
