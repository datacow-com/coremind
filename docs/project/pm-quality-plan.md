# OmniRAG 项目管理与质量计划

## 1. 项目概述与目标

OmniRAG是一个基于LangGraph架构的智能文档处理与问答系统，核心创新在于视觉化PDF文档处理流程。项目旨在提供高精度、低幻觉率的文档理解和问答服务。

## 2. ACIS分层WBS与Backlog

### 2.1 ACIS分层架构

**A层 - 应用层 (Application)**

- A1: 用户界面与交互
- A2: API接口服务
- A3: 可视化展示

**C层 - 核心层 (Core)**

- C1: LangGraph工作流引擎
- C2: 视觉PDF处理模块
- C3: 文档检索与问答

**I层 - 基础设施层 (Infrastructure)**

- I1: Milvus向量数据库
- I2: PostgreSQL检查点存储
- I3: FastAPI服务框架

**S层 - 支撑层 (Support)**

- S1: 监控与日志
- S2: 测试与质量保证
- S3: 部署与运维

### 3.2 性能指标定义

- **TTFT (Time To First Token)**: 首token生成时间 ≤ 500ms
- **QPS (Queries Per Second)**: 查询每秒 ≥ 100
- **Top-10命中率**: 相关文档在前10结果中的比例 ≥ 85%
- **表格还原准确率**: 表格结构识别正确率 ≥ 95%
- **PII检出率**: 个人敏感信息识别率 ≥ 99%
- **幻觉率**: 生成内容中不真实信息比例 ≤ 5%
