# OmniRAG 缺失特性执行任务清单（确保实现与质量）

## 目标

- 将审查中识别的缺失/薄弱特性转化为可执行任务，明确范围、交付、验收与质量度量
- 以产品体验为锚点，突出视觉解析与可解释检索优势，保证过程透明、可调参、可验证

## 优先级与阶段

- P0：核心体验与能力可视化（立即）
- P1：生态扩展与运营分析（两周内）
- P2：安全与平台化生态（迭代）

---

## P0 任务

### 1. Figure 理解与索引（Caption）

- 范围：为图片块生成文字描述并入库，检索与来源展示区分 `figure`
- 后端改动：
  - 在 `VisualPDFLoader` 增加 `vision_caption(image_bytes)` 并写入 `metadata: { block_type: "figure", caption }`
  - 在索引流程中将 `figure` 片段加入向量与关键词索引
- 前端改动：
  - Chat 右侧预览显示 `figure` 徽章与 `caption`
  - 来源列表支持 `Figure` 过滤
- 验收标准：
  - 随机 10 张图的 `caption` 准确率主观评分 ≥ 0.8；来源显示包含 `Figure`
- 质量度量：
  - 成功生成率、检索命中率、人工质量评分
- 测试与验证：单元（loader）、端到端（摄取→检索→展示）

### 2. 动态分块策略（semantic/fixed/parent-child）

- 范围：提供三种分块策略及 Settings/运行时开关
- 后端改动：
  - `ParsingRule` 扩展 `mode` 字段；不同策略下的 `_chunk_text` 行为
- 前端改动：
  - Settings 增加分块策略选择；聊天页显示当前策略
- 验收标准：
  - 三种策略可切换并生效，chunk 平均长度与数量符合预期范围
- 质量度量：
  - chunk 长度分布、索引覆盖率、检索召回影响评估
- 测试与验证：策略切换集成测试、检索效果对照

### 3. 两段式检索与重排（candidate_k→rerank→top_k）

- 范围：引入候选规模与重排阈值，形成两段式策略
- 后端改动：
  - `retrieve` 支持 `metadata.candidate_k` 扩大量；`rerank` 基于 `candidate_k` 输入与 `reranker_threshold`
- 前端改动：
  - Settings 增加 `candidate_k` 与 `reranker_threshold`；聊天页顶部新增微指标卡片（候选数、耗时、均值、最终 Top-K）
- 验收标准：
  - 候选规模生效且可观察；重排均值与保留阈值与 UI 一致显示
- 质量度量：
  - 检索耗时、候选数、重排均值、Top-K 命中率曲线
- 测试与验证：后端单元、前端可视验证、A/B 权重对照

### 4. 流程与能力可视化（阶段时间线 + 指标卡 + 来源徽章）

- 范围：在 Chat 页构建“阶段时间线”与微指标卡，来源分组与徽章呈现
- 后端改动：
  - SSE `phase` 增加关键指标展平字段；可选输出 `thought` 文案
- 前端改动：
  - 时间线组件（route→retrieve→rerank→grade→web_search→generate→hallucination）；来源分组（内部/外部）；徽章显示 `block_type/hlevel/table_id`
- 验收标准：
  - 时间线与指标按阶段准确显示；来源分组与筛选可用
- 质量度量：
  - 指标渲染正确率、用户操作路径耗时、错误率
- 测试与验证：流式会话 E2E、可视化回归

### 5. SSE 协议补齐（thought 与 final 汇总）

- 范围：兼容文档的 `event: thought` 与最终汇总指标
- 后端改动：
  - 在阶段运行时输出 `thought` 描述；`final` 增加 `metrics_summary`
- 前端改动：
  - 时间线节点显示 `thought`；会话结束显示汇总
- 验收标准：
  - 有描述时 `thought` 正确呈现；汇总包含 tokens/duration/avg_scores
- 质量度量：
  - 事件兼容、丢失率、渲染一致性
- 测试与验证：协议契约测试、端到端日志核对

## P1 任务

### 6. 嵌入与发布（Headless + JS SDK）

- 范围：新增“嵌入与发布”页，输出 JS SDK 片段与独立 URL
- 后端改动：
  - 生成发布配置与静态页；跨域与令牌策略
- 前端改动：
  - `PublishPage` 展示 SDK、配置说明、一键复制
- 验收标准：
  - 第三方页面可嵌入并正常对话；安全策略可配置
- 质量度量：
  - 首字延迟、加载错误率、跨域成功率
- 测试与验证：真实外域嵌入验证

### 7. 运营分析增强（热词/负样本池/TTFT/吞吐）

- 范围：Usage 看板扩展热词 Top-N、点踩负样本池、TTFT/吞吐曲线
- 后端改动：
  - 统计管线完善与聚合接口
- 前端改动：
  - Usage 页图表组件与列表交互
- 验收标准：
  - 指标数据与文件聚合一致；交互响应良好
- 质量度量：
  - 数据完整性、渲染性能
- 测试与验证：聚合单元与图表快照对比

### 8. 任务绑定矩阵与模型链路测试

- 范围：解析/检索/对话/重排任务矩阵配置与一键测试
- 后端改动：
  - 绑定接口扩展与测试路由输出 ttft/throughput/error_rate
- 前端改动：
  - Settings 矩阵视图与测试按钮，显示测评结果
- 验收标准：
  - 各任务链路测试结果可视与存档
- 质量度量：
  - 测试成功率、指标可信度
- 测试与验证：路由与 UI 联调测试

### 9. 向量库可用性与集合状态呈现

- 范围：Milvus/本地索引可用性、集合状态与降级提示
- 后端改动：
  - 集合状态接口补充可用性标志
- 前端改动：
  - Vector Store 页显示状态徽章与降级文案
- 验收标准：
  - 服务不可用时前端明确提示与降级说明
- 质量度量：
  - 状态正确率、误报率
- 测试与验证：服务开关联动测试

## P2 任务

### 10. RBAC 与多租户

- 范围：后端路由与数据域权限控制、租户隔离；前端权限视图
- 验收标准：
  - 不同角色访问受限；租户数据不可越权
- 质量度量：
  - 权限覆盖率、越权用例通过率
- 测试与验证：权限单元与集成用例

### 11. OpenAPI 文档与契约测试

- 范围：覆盖 ingest/index/search/chat/metrics/gateway 等接口
- 验收标准：
  - 文档完整、与实现一致；契约测试通过
- 质量度量：
  - 文档更新滞后率、契约断言通过率
- 测试与验证：自动化契约测试

### 12. PII 过滤与执行沙箱

- 范围：上下文注入前的敏感信息掩码；执行类工具使用容器沙箱
- 验收标准：
  - PII 用例均被掩码；执行环境隔离生效
- 质量度量：
  - 误掩码率、漏掩码率、沙箱隔离事件
- 测试与验证：PII 样本与沙箱集成测试

---

## 统一验收与质量门槛

- 指标与日志
  - 流式：TTFT、生成速率（c/s,w/s）、阶段耗时与计数
  - 检索：候选规模、融合得分、重排均值、Top-K 命中
  - 摄取：表格识别率、Caption 生成率与质量评分
- 测试与校验
  - 单元测试最小覆盖：Loader/检索/重排/路由
  - E2E：摄取→索引→检索→生成→展示
  - 协议契约：SSE 事件类型与字段一致性
- 文档与演示
  - 每项任务提供简要使用说明与演示用例链接

## 里程碑与交付

- M0（P0 完成）：核心体验上线，时间线与指标卡可视，Figure/策略/两段式检索落地
- M1（P1 完成）：发布/嵌入、运营看板增强、绑定矩阵与向量库状态
- M2（P2 完成）：安全与平台化生态（RBAC、OpenAPI、PII/沙箱）

## 风险与缓解

- 视觉成本与速率：默认 OCR，复杂度触发视觉；配额与速率监控
- 向量库可用性：降级至本地索引；前端状态告知
- 算法调参复杂：显式策略开关与可视指标降低黑盒感
